BacaPop Next.js - Moving Cards Version

Cara menjalankan:
1. Extract folder ini.
2. Buka terminal di folder ini.
3. Jalankan: npm.cmd install
4. Jalankan: npm.cmd run dev
5. Buka http://localhost:3000

Catatan:
- File halaman utama memakai app/page.js, bukan page.jsx.
- CSS dipisah: app/page.module.css dan app/globals.css.
- Interaksi: klik card mana pun, card tersebut berpindah ke tengah dan berubah menjadi card utama.
